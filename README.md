# Chander Parkash Portfolio

Single-page, high-performance portfolio site built with semantic HTML, CSS, and vanilla JavaScript.

## Structure

- `index.html` — Main page with structured data and SEO meta tags
- `styles.css` — Design system, layout, and animations
- `script.js` — Interactions, animations, and UI logic
- `assets/` — Profile image, CV PDF, Fiverr review screenshots
- `sitemap.xml` — Section anchor sitemap
- `robots.txt` — Crawl rules and sitemap reference
- `manifest.json` — PWA manifest

## Notes

- External libraries via CDN: GSAP, Vanta.js (Three.js), AOS, Typed.js
- CV download uses `assets/CV (Resume) - Chander Parkash - Java Spring Boot.pdf`
